# MC&DJ Hub

Plataforma integral de gestion empresarial para MC&DJ Consultores y Evaluadores Profesionales.

## Version actual

**v0.2 - Identity**

## Proposito

MC&DJ Hub sera el centro operativo digital del despacho. Integrara en una sola plataforma los procesos internos, herramientas fiscales y financieras, gestion de clientes, expedientes, proyectos, cobranza, indicadores e inteligencia artificial.

## Principios del producto

1. Una sola plataforma para operar el despacho.
2. Un solo usuario, un solo login y una sola identidad visual.
3. La informacion no debe capturarse dos veces.
4. Cada modulo debe ahorrar tiempo, reducir errores o mejorar el control.
5. La IA debe asistir al criterio profesional, no sustituirlo.
6. Cada sprint debe dejar el sistema mas seguro, mas claro y mas mantenible.
